# v2.6.1 更新日志 · 体验优化版

> 发布日期：2026-09-12 ｜ 版本类型：小版本（v2.6 → v2.6.1）
> 说明：v2.6 存档可直接继续玩，打开旧存档会自动补齐新字段。

---

## 🐛 重大修复

### 世界日志"乱码"修复
- **问题**：AI 流式撰写（加载中）时，世界日志会显示一大段 `{"advance":...,"narrative":"..."}` 花括号符号，像乱码一样。
- **修复**：流式接收时只把返回数据里的**剧情正文**实时提取出来显示，正确还原换行、引号和中文；加载提示改为"✍ AI 正在撰写这段剧情…"。
- 空操作推进（"自行推进"）时的选项显示同步修复。

## ⚡ 我的行动 · 界面重做

- **界面精简**：删除原来重复的两组推进按钮，现在只有三个主操作：
  - **✅ 按选择推进**
  - **🌙 自行推进**（过几天，世界自己运转）
  - **⚡ 到有事件发生**（直奔剧情）
  - 周 / 月 / 季 / 年长时间快进收进下方小字入口
- **A/B/C 支持多选**：点一下卡片即"亮灯"选中（金色描边 + 呼吸发光 + 右上对勾），可同时点亮多个方向，再点取消。
- 多选后推进会把多个方向按「；同时，」合并成一条行动；AI 被明确要求**按先后顺序逐一处理，不许揉成一句话**。
- 自定义输入框常驻，可只选方向不写字，也可只写字不选方向；Ctrl+Enter 快捷键同步适配。

## 📜 世界日志 · 日期选项卡

- 从"只能上下翻的纯文字长流"改为**按天分页的时间轴**：
  - 顶部吸顶日期选项卡，左右滑动切换（年份小字 + X月X日 + 当天条数角标）
  - **关键事件日**带红色呼吸点 + 红框（大事件 🔴 / 人生大事 / 里程碑当天）
  - 默认停在最新一天，跨天自动跟随；手动翻看旧日时不会被打断
- 修好了长日志无关刷新时的闪烁/滚动跳动。

## 🔊 音效与触感

- 新增 Web Audio 实时合成音效（不加载任何音频文件）：点亮选项 / 推进剧情 / 撞上大事件 / 解锁成就 各有不同提示音。
- 手机端附带轻微震动反馈（`navigator.vibrate`）。
- 可在「🎨 外观」面板一键关闭，本机自动记忆选择。

## 🧭 新手引导

- 首次进入游戏自动播放 3 步浮层引导（世界日志 → 点亮方向 → 开始推进），本机只弹一次，可随时跳过。

## 📤 人生回顾导出

- 「人生回顾」弹窗新增 **📋 复制全文** 和 **⬇ 导出 TXT**（含基本信息、成就、里程碑、人生大事与版权尾注，UTF-8 编码），方便存档与分享。

## 🤖 AI 推理优化（不降智）

- 主推演与辅助 AI 两条调用路径合并，统一请求构建逻辑（关思考链 / top_p 0.85 / 强制 JSON / 流式），后续调参只改一处。
- 系统提示词（装备规则等静态内容）压缩约 2/3，每回合更省 Token、返回更快；剧情规则一条未减。
- 世界推进时间跨度更合理：有行动 **2~5 天**、无行动 **7~14 天**（原先只有 1~2 小时，MCU 七十年时间线几乎推不完）。
- AI 返回的 Key 改为分段存储（基础防直接复制）；真正安全仍以后端代理为目标。

## 🎨 美术 / 多端

- 全站接入「思源黑体（Noto Sans SC）」，Windows 端不再退回微软雅黑。
- 顶部按钮全部换成统一风格 SVG 图标，iOS / 安卓 / Windows 显示一致。
- 新增首屏加载骨架，消除 1.28MB 页面打开时的白屏；"支持"收款码空闲预加载，点击秒开。
- 尊重系统「减弱动态效果」设置：开启后关闭呼吸/闪烁/浮动动画。
- 安全区、横屏断点、手机端毛玻璃降级等多端细节继续修正。

## 💾 存档兼容

- 读档自动补齐装备库 / 能力 / 组织 / 章节 / 能力值等新字段，老版本存档平滑打开、不报错。
- 内部清理：简易/专家模式遗留死代码、重复内联样式等。
