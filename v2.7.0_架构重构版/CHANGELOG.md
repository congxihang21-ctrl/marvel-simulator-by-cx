## ✨ 新玩法：⟲ 章节回溯（人生重来）

- 每个 **🔴 英雄级大事件** 与 **🌟 改写历史瞬间**，系统会在你做选择**之前**自动建立一个**章节存档点**（时间轴上带 ⟲ 星标）；
- 在编年史 → 事件详情卡底部点 **「⟲ 从这一天重新选择」**：
  - 先**自动备份当前进度**（写入本机独立存储 + 下载一份存档文件双保险）；
  - 然后回到那个节点，**此后的历史全部作废重来**，你可以做出不同选择、走向不同人生；
  - 被废弃时间线里更晚的存档点自然清除，当前回溯点保留；
- 存档点最多保留 4 个、总体积约 900KB 预算，超出自动从最旧淘汰，不会撑爆本机存储。

## ✨ 编年史系统（承接 v2.6.4 / v2.6.5，本版合入）

- 主页「📖 打开完整编年史」：纵向时间轴、自动分章、月份快跳（大事月带红点）、类型筛选；
- 事件详情卡：完整正文、当时 A/B/C 选项与你的选择、📸 人物状态快照、🌍 世界局势快照、上一件/下一件连续翻看。

## 🏗 架构改造（第一轮，为后续模块化铺路）

新增 `js2/core/` 零依赖内核（无构建工具，浏览器原生加载）：

| 文件 | 职责 |
|---|---|
| `store.js` | 发布订阅状态仓库 `MCU.createStore` + 跨模块事件总线 `MCU.bus`，新功能不再靠全局 S + 全量 renderAll 兜底 |
| `savekit.js` | 存档 **schema 版本**（`_schemaV`）+ 幂等迁移链 + 写满配额时的显式安全写入 |
| `diag.js` | 全局诊断系统：`window.onerror`/未处理 Promise 全部入内存环形缓冲；设置 →「🩺 诊断日志」可查看、一键复制发作者 |

- 版本号唯一真相源 `APP_VERSION` 统一页脚/标题/资源 URL（自 v2.6.3 起），所有资源版本号随版本提升，根治"改了代码手机还是旧版"的缓存问题；
- 存档写入增加存档点数量硬保险与 schema 版本戳。

> 说明：app.js 历史包袱（7000+ 行单体）按"内核先行、模块逐个迁移、线上始终可玩"的策略改造，本版落地内核与首个使用方（编年史/回溯），后续版本将逐块把回合调度、AI、UI 迁入新内核，不做风险不可控的一次性重写。
