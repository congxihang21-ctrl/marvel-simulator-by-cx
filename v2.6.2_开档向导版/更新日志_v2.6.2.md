## 🌍 世界自主运转引擎（世界时钟 WorldClock）· 2026-09-13 追加更新

这颗新的"世界心脏"让世界**不再围绕玩家转，而是自己在运行**：

- **正典到点必发生**：77 条 MCU 正典大事件挂在真实日历上。不管你在上班还是睡觉，时间一跨月，该发生的就会发生——2016 内战、2018 灭霸响指、2023 终局……都会准时降临，并以「🌍 世界头条 / 🔴 世界大事件」卡片进入你的人生时间线。
- **普通人只是被间接影响**：默认你只通过电视新闻、街头议论、物价与恐慌感受到世界变化，不会被强行拉去选边；想入局，要自己选择靠近。
- **正典可以被你改写**：引擎内置因果规则。例如你 2017 年就设法阻止了灭霸，那么 2018 的响指、烁灭五年、量子劫案、终局之战、烁灭者回归会整条连锁**取消或改写**，头条标注「🌟 已被你改写」，世界按新轨迹继续。已入局者在大事件前 18 个月有机会收到「🌪 风雨欲来」干预节点，赌上一切尝试逆天改命（高风险判定）。
- **双开局轨**：创角时若选择了超能力/特殊职业资质，开局会识别为「能力者」，可直接走英雄/职业路线；纯普通人则从柴米油盐起步，靠自己的选择一步步走进非凡世界。
- **世界日志重做**：大段文字改成**头条卡片流**——图标 + 日期 + 一行标题，默认折叠，点一下展开看现场；红边=大事件、金边=你改写的历史；顶部「全部 / 🌍 世界 / 🙂 我的」频道筛选，关键日期 tab 带红点。
- **AI 与引擎对账**：AI 每回合会收到「已发生的世界大事（既成事实）」与「已被你取消的正典」，不会重复播报已发生的事件，也不会让被改写的事件死灰复燃。

> 旧存档打开后世界时钟自动从当前日期接管，不会补播过去的事件，安全兼容。

## 🔧 缓存根治 + 顶栏精简（2026-09-13 追加）

**SW 缓存根治（以后发版不用再手动清缓存）：**
- `sw.js` 自身**永不缓存**，永远走网络——这是反复卡死的根因（旧 SW 把旧 sw.js 缓存住，浏览器永远检测不到更新）
- HTML 导航请求网络优先，`updateViaCache:'none'`，每 10 分钟主动检查更新
- `selfHeal`（🔧 修复）改为从页面直接注销所有 SW + 清缓存，不再依赖 SW 是否认消息，带 3 秒兜底强制重载

**顶栏 / Tab 再精简：**
- 删除顶部按钮条（外观/存档/读档/人生回顾/关于/支持/修复），全部迁入新增的 **⚙️ 设置 Tab**（第 6 个，最右侧）
- 大时间卡 → 紧凑成一行顶栏（OVR 徽章 + 日期 + 轮次），不再占大块空间
- 目标条：标题精简为「当前目标」，文案去掉冗长括号注释和「即将开始」等套路化后缀
- 「我的」Tab 新增「📜 人生回顾」入口
- `gameBottomBar` 隐藏（功能已在设置 Tab）

## 🚪 恢复存档选择弹窗（2026-09-13 追加·第二轮）

**问题**：之前刷新页面后会自动 `enterGame()`，重型同步渲染（buildPanels + renderAll + 引擎 init）在手机上被误判为"卡死"，停在"已回到你的人生"提示上。

**修复**：
- 恢复存档后**不再自动进游戏**，改为弹出选择弹窗：
  - **▶ 继续上次的人生**（金色主按钮，回车可直接续玩）
  - **🏠 回到主页，开新存档**（清空内存 S，存档还在 localStorage，可随时读档恢复）
- 弹窗显示英雄名、时代、日期、轮次，让用户确认是自己的存档
- `enterGame()` 加 `busy('正在载入你的人生…')` 加载遮罩，渲染期间不再像卡死

## 🔨 iOS Safari 卡死根治 + 缓存死锁爆破（2026-09-13 第三轮）

**问题**：iOS Safari 打开链接直接卡死，无法交互。两个根因：
1. **缓存死锁**：旧 SW 把旧 sw.js / 旧 2.6.2.html 缓存住，用户永远拿不到修复版
2. **iOS 同步渲染卡死**：旧代码刷新后自动 `enterGame()`，`buildPanels + renderAll + 3引擎init` 全是同步重活，iOS Safari 主线程被堵死，页面完全无响应

**修复**：
- **新入口 `2.6.2_fix.html`**（换文件名打破旧 SW 缓存）：
  - 页面最顶部脚本：检测到旧 SW 立即 `unregister` + 清空所有 Cache Storage，只执行一次（localStorage 标记）
  - `index.html` 和旧 `2.6.2.html` 都跳转到此文件
- **`enterGame()` 彻底异步化**：
  - 先显示「正在载入你的人生…」遮罩
  - `setTimeout(0)` 让出主线程让遮罩先绘制
  - 分两帧执行：第一帧 `buildPanels + 引擎init`，再 `setTimeout(0)` 让一帧，第二帧 `renderAll`
  - 12 秒看门狗：busy 遮罩超时强制收起，杜绝永久卡死
- `sw.js` 缓存版本升至 `v2.6.5`，CORE 列表加入 `2.6.2_fix.html`

## 🧭 开档流程重做：分步向导

参考 career-sim（足一把·生涯模拟器）的分步式创角，把原来「6 组手风琴一口气铺开」的长表单，改成**点一个、下一步、进入下一屏**的 5+1 步向导：

1. **🕰 世界线** —— 时代 + 出生地/居住地
2. **🌱 血统与出身** —— 血统 + 出生身份（可整步跳过）
3. **🪪 你是谁** —— 姓名 / 性别 / 年龄 / 家庭
4. **⚡ 能力与装备** —— 能力资质 / 初始技能 / 初始装备
5. **🎯 性格与目标** —— 阵营 / 性格关键词 / 初始目标（可整步跳过）
6. **✅ 总览确认** —— 分组列出你的全部选择，确认后再进入世界

配套细节：

- **顶部金色进度条**：20% → 40% → 60% → 80% → 100%，随时知道自己在第几步。
- **竖向大选项卡**：原生下拉框全部隐藏，选项变成一行一张大卡，选中有金色描边 + 发光 + 右侧 ✓，手机上单手好点。
- **底部固定毛玻璃操作条**：「← 上一步 / 返回首页」+「继续 →」永远在屏幕底部，长列表滚到底也不用找按钮；最后一步按钮变成金色呼吸的「⚔ 进入世界」。
- **每步一句灰色副标题**，说明这步选择影响什么；可跳过的步骤有明确「留空 AI 替你安排」提示。
- **自定义不丢**：选「✏️ 自定义」后卡片下方展开输入框；空着点继续会被拦住并提示是哪一项。能力资质等原本没有自定义入口的字段，向导里统一补上了「自定义」卡。
- **可进可退**：任意一步都能返回修改，已填内容不丢失；总览页所有字段一目了然，留空项显示「✨ 交给 AI 安排」。

- 借鉴的是参考站的**交互结构**（分步、进度条、大卡、固定底栏、总览、数据条），视觉仍沿用本作 MCU 电影风的**金色 + 深色 Liquid Glass**，没有照搬绿色足球主题。
