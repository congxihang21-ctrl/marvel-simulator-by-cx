## 🧭 开档流程重做：分步向导

参考 career-sim（足一把·生涯模拟器）的分步式创角，把原来「6 组手风琴一口气铺开」的长表单，改成**点一个、下一步、进入下一屏**的 5+1 步向导：

1. **🕰 世界线** —— 时代 + 出生地/居住地
2. **🌱 血统与出身** —— 血统 + 出生身份（可整步跳过）
3. **🪪 你是谁** —— 姓名 / 性别 / 年龄 / 家庭
4. **⚡ 能力与装备** —— 能力资质 / 初始技能 / 初始装备
5. **🎯 性格与目标** —— 阵营 / 性格关键词 / 初始目标（可整步跳过）
6. **✅ 总览确认** —— 分组列出你的全部选择，确认后再进入世界

配套细节：

- **顶部金色进度条**：20% → 40% → 60% → 80% → 100%，随时知道自己在第几步。
- **竖向大选项卡**：原生下拉框全部隐藏，选项变成一行一张大卡，选中有金色描边 + 发光 + 右侧 ✓，手机上单手好点。
- **底部固定毛玻璃操作条**：「← 上一步 / 返回首页」+「继续 →」永远在屏幕底部，长列表滚到底也不用找按钮；最后一步按钮变成金色呼吸的「⚔ 进入世界」。
- **每步一句灰色副标题**，说明这步选择影响什么；可跳过的步骤有明确「留空 AI 替你安排」提示。
- **自定义不丢**：选「✏️ 自定义」后卡片下方展开输入框；空着点继续会被拦住并提示是哪一项。能力资质等原本没有自定义入口的字段，向导里统一补上了「自定义」卡。
- **可进可退**：任意一步都能返回修改，已填内容不丢失；总览页所有字段一目了然，留空项显示「✨ 交给 AI 安排」。

## 🎨 设计说明

- 借鉴的是参考站的**交互结构**（分步、进度条、大卡、固定底栏、总览、数据条），视觉仍沿用本作 MCU 电影风的**金色 + 深色 Liquid Glass**，没有照搬绿色足球主题。
- 固定底栏特意挂在页面最外层（`.screen` 容器自带 transform 会让 fixed 定位失效），滚动页面时底栏始终钉在视口底部。
- 手机竖屏优先（390px 断点适配），桌面端居中 680px 显示。

## ♻️ 兼容性与清理

- 向导复用原有字段管线（FIELDS / fieldValue / validateForm / startGame），AI 提示词、开局数据格式零变化，**所有旧存档正常读取**。
- v2.2 手风琴创角相关的废弃 JS / 样式随本次重写清理。
