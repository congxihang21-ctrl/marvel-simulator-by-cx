🚀 推荐档 = 作者共享 AI 池优先 · 零配置开玩
· 当前共享池：加载中…   默认模型：—
· 优先级链路：作者部署代理 → 作者内置智谱 Key → 你自填的 Key → 离线兜底（4 层透明降级，绝不卡进度）
· 作者已把 Key 硬编码在 HTML 中了，朋友拿到这份 HTML 直接就可以点「▶ 推进」开始 AI 文笔，无需注册任何平台。
💡 本 HTML 只分享给 2-3 个朋友使用；对外公开发布时，请务必把 【CX_SHARED_KEY】 清空后再传，避免泄露 API Key！
👇 想自己换模型 / 用自己的额度？切换到上面的「🧠 自定义 API」卡片填自己的 Base+Key+Model 即可（推荐档会自动复用你的 Key，不用重复填）。
📌 推荐档无需保存，关窗即生效。如果当前显示"作者共享 AI 池已就绪"，直接关掉本窗口开始玩即可。
⚠ 浏览器直连会把 API Key 暴露给接口服务商，部分接口还会因 CORS 拒绝网页直连。本地 / 自建服务最安全。若报错 Failed to fetch，多为 CORS，起一个本地服务打开即可。
